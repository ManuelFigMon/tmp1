                    How to Update Configurable Variables
                

                
            


            

                

                    All settings for SQL Studio Browser Runner_v3 are centralized in the APP_CONFIG object, which in v3 lives in its own <script> block inside the <head> — the very top of the file, above all CSS and markup.
                


                

                    
// Code structure inside <head><script>:

                    
const APP_CONFIG = {
    SERVER_HOST: "A70TUCGSDATA008.A70ADMED.COM",
    INITIAL_CATALOG: "DataMartKYA",
    PORT: 1433,
    AUTH_MODE: "Integrated Security (SSPI / NTLM)",
    AUTH_MODE_OPTIONS: [ ... ],
    PRESET_WORKLOADS: [
        {
            name: "SAS Migration: Hello World Query",
            sql: "SELECT 'Hello World' AS Greeting;"
        },
        ...
    ]
};

                


                

                    
Step-by-Step Instructions:

                    
    
                        
  1. Open this .html file in any text or code editor (VS Code, Notepad++, Sublime Text).
    2. 
                        
  2. Scroll to the top — const APP_CONFIG is in the <head>, before any CSS.
    3. 
                        
  3. Modify SERVER_HOST, INITIAL_CATALOG, PORT, or AUTH_MODE.
    4. 
                        
  4. To add an authentication mode, append a string to AUTH_MODE_OPTIONS — the dropdown is built from that array, so no HTML edit is needed.
    5. 
                        
  5. To add a SQL template, insert an object with name and sql into PRESET_WORKLOADS.
    6. 
                        
  6. Save the file and refresh your browser.
    7.
