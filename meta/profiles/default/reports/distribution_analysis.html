About DMQ — Distribution Analysis

The Distribution Analysis report provides statistical insight into how metric values are spread across categories within your selected dataset.

It computes percentiles, quartiles, standard deviation, mean, and Z-scores, and renders an interactive bell curve, line chart, and bar+line combo chart.

Built with D3.js v7 and vanilla JavaScript — no frameworks required.

Help & Support

Thank you for using DMQ — Distribution Analysis. Select a dataset, choose a numeric metric column and a character category column, then apply any filters to refine your results.

The charts will render automatically as you make selections.
