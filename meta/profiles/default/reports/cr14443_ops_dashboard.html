About CR 14443 API Operations

This is a static GUI mockup. No backend, no live API calls — every figure on this page is derived client-side from an embedded snapshot of 500 synthetic CR 14443 API call records (June 2026). No PHI is present.

CR 14443 establishes the electronic exchange of prior-authorization Additional Documentation Request (ADR) responses between CMS's intermediate PCG FHIR system and the MACs. The MAC is notified of a response, retrieves the SIMPLE-format package, verifies each document's SHA-256 hash, acknowledges retrieval, and records a review decision within the 7-calendar-day window.

The pipeline, SLA table, error queue, and analytics are all recomputed from the same embedded dataset using 2026-06-30 23:59 UTC as the operational reference time.
