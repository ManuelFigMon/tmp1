About DMQ — Hexbin Plot

The Hexbin Plot groups (X, Y) data points into hexagonal bins and colors each bin by the number of points it contains. This makes it ideal for large datasets where ordinary scatter plots suffer from overplotting.

How it works

  • The plot area is divided into a regular hexagonal grid.
  • Each data point is assigned to the nearest hex center.
  • Bins are colored from light blue (few points) to dark blue (many points), using a sequential color scale.
  • A count legend on the right shows the mapping from color to count.

Controls

  • X Axis / Y Axis: Choose two numeric columns.
  • Group Column (optional): A character column for labeling the character legend below the plot.
  • Hex Radius: Controls the size of each hexagon. Larger = coarser bins; smaller = finer resolution.
  • Min Count: Hides bins with fewer than N points to reduce visual noise.
  • Color Scheme: Switch between Blues, Greens, and Purples sequential scales.
  • Show Axes: Toggle axis lines and tick labels.

Interpretation

Dark concentrated areas reveal the densest regions of your data. Light or sparse areas indicate fewer observations. Use the Min Count slider to focus on high-density areas.

Built with D3.js v7 and vanilla JavaScript — no frameworks required.

Help & Support

Select a dataset, choose X and Y numeric columns, then the hexbin plot renders automatically.

Use the Hex Radius slider to control bin granularity. A radius of 15–25 pixels works well for most datasets.

The Min Count filter hides low-density bins to reveal structure in dense regions.
