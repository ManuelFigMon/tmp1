About DMQ — Time Series Explorer

The Time Series Explorer draws one or more measurements as connected lines over time, so you can see trends, cycles, sudden jumps, and gradual drift at a glance. Each dot is one observation; the line simply connects consecutive observations in time order.

Overlaid series

Every numeric column you select becomes its own line. If you also pick a Group/Legend column (a character variable), the data is split by each distinct value of that variable, and each value gets its own colored line and legend entry. Selecting both produces one line per Y-column × group-value combination (capped at 20 series to stay readable).

Reference lines

  • Mean (dashed): the arithmetic average of a series — sensitive to extreme values.
  • Median (dashed): the middle value — half the points are above it, half below; robust to outliers.
  • Mode (dotted): the most frequently occurring value (values are rounded slightly to find ties in continuous data).
  • P25 / P75 (light dashed): the 25th and 75th percentiles — the middle 50% of values fall between these two lines.

Outlier exclusion (1.5×IQR)

When "Include outliers" is unchecked, points are dropped if they fall more than 1.5 times the interquartile range (IQR = P75 − P25) below P25 or above P75 — the standard box-plot fence rule. The KPI strip reports how many points were excluded.

Minimum points ("best so far")

With "Highlight minimum points" on, every time a series sets a new all-time low it is marked with a larger red dot, and a red dashed step line tracks the best (lowest) value achieved up to each moment — like a personal-best line on a race-time chart. The lower it steps, the better the record.

Linked data grid

The table below the chart shows every underlying row. Selection is bidirectional: clicking a point on the chart selects (and scrolls to) its row in the grid, and ticking row checkboxes in the grid enlarges and rings the matching chart points while dimming the rest. Use Clear Selection to reset both.

Built with D3.js v7, AG Grid Community, and vanilla JavaScript — no frameworks required.

Help & Support

Thank you for using DMQ — Time Series Explorer.

Quick steps:

  • 1. Choose a dataset.
  • 2. Pick an X-Axis (date/time) column and one or more numeric Y-Axis columns (Ctrl/Shift to multi-select).
  • 3. Optionally pick a Group/Legend character column to split lines by category.
  • 4. Add filters and adjust the Configuration toggles — the chart updates live.
  • 5. Click chart points or grid rows to cross-highlight; use the grid's quick filter, sorting, and pagination to explore.

If you encounter any issues, have questions, or would like to suggest improvements, please reach out.
