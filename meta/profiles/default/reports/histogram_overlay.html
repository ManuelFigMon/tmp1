About DMQ — Histogram Overlay

Histogram Overlay displays the frequency distribution of a numeric variable as a series of bars (bins). Each bar shows how many records fall within that value range.

Overlaying multiple histograms (one per group) lets you visually compare how different groups are distributed — for example, comparing the age distribution of first-class vs. third-class passengers.

Key elements:

  • Bins: The X-axis is divided into equal-width intervals. Bin count can be set manually or computed automatically (Sturges, Square Root, Scott's rule).
  • Bar height: In Count mode, height = number of records in that bin. In Density mode, height is normalized so the total area = 1, enabling comparison across groups of different sizes.
  • KDE Curve: The Kernel Density Estimate is a smoothed approximation of the distribution. It uses a Gaussian kernel with bandwidth chosen by Silverman's rule (adjustable via multiplier).
  • Mean / Median lines: Optional vertical reference lines per group.
  • Normal Curve: Shows what a perfect normal distribution would look like given the data's mean and standard deviation — useful for assessing normality.
  • Opacity: Lower opacity lets overlapping histograms show through each other (key for comparing groups).
  • Legend: When a grouping column is selected, each unique value becomes a separate histogram with its own color shown in the legend.

Use cases: Comparing distributions across demographic groups, fraud risk segments, time periods, or any categorical split of your data.

Help & Support

Thank you for using DMQ — Histogram Overlay. Select a dataset, choose a numeric metric column, and optionally select a grouping column to overlay distributions by group.

Use the Configuration panel to control bin count, KDE smoothing, opacity, and display options. Charts update automatically as you change settings.
