About DMQ — K-Means Cluster Analysis

The K-Means Cluster Analysis report partitions your data into k groups (clusters) by minimizing the within-cluster sum of squared distances to the centroid.

It renders an interactive scatter plot with convex hull polygons per cluster, centroid markers, and a per-cluster summary table showing count, mean, and standard deviation for both axes.

The K-Means algorithm is implemented in pure vanilla JavaScript using a seeded pseudo-random number generator for reproducibility. Built with D3.js v7 — no frameworks required.

Help & Support

Thank you for using DMQ — K-Means Cluster Analysis. Select a dataset, choose two numeric columns for the X and Y axes, configure the number of clusters (k), then apply any filters to refine your results.

The scatter plot and cluster summary table will render automatically. Use the Re-run Clustering button to re-run with the current settings, or change the Random Seed for different initial centroid placements.
