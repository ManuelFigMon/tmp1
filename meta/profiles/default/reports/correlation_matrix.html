About DMQ — Correlation Matrix

The Correlation Matrix report computes pairwise Pearson correlations between selected numeric columns and renders an interactive heatmap.

Pearson correlation ranges from -1 (perfect negative) to +1 (perfect positive). Values near 0 indicate no linear relationship.

Built with D3.js v7 and vanilla JavaScript — no frameworks required.

Help & Support

Thank you for using DMQ — Correlation Matrix. Select a dataset, choose two or more numeric columns, and optionally apply filters to refine your data.

The heatmap renders automatically. Hold Ctrl/Shift to select multiple columns in the listbox.
