What happens when you save
The change is written to [dbo].[Job].[JobName] through the dmw_update stored process, keyed on JobID, and the grid reloads. Your SAS username is recorded server-side. If someone else renamed this job since the grid loaded, the save is refused rather than overwriting their change.
About DMW -- IT Management Solution

DMW (Data Mart Workbench) -- IT Management Solution monitors SAS Scheduler job activity held in SQL Server. It executes a SQL statement through a SAS Stored Process and renders the returned JSON in an AG Grid, with dashboard, visualisation and CSV export views.

How it reaches the database

A browser cannot connect to SQL Server directly: SQL Server speaks the TDS protocol over a raw TCP socket on port 1433, and browser JavaScript has no raw TCP socket API. Windows Authentication additionally requires OS-level credential delegation that a sandboxed page is never granted.

This page therefore calls the SAS Stored Process dmw_run, which holds the OLE DB connection and returns the result set as a JSON array. Nothing is installed on the workstation.

Browser --HTTPS &dmq_query=<SQL>--> dmw_run (SAS) --OLEDB--> SQL Server

Configuration

Every adjustable value lives in the CONFIG object in a <script> block at the very top of this HTML file, above the stylesheet and markup. The database connection itself is made by the stored process, so the DMW_* macro variables at the top of dmw_run.sas must describe the same target.

Help & Support

Getting started

  1. Press Logon in the top right. You are redirected to SAS, authenticated, and returned here. The query then runs automatically.
  2. Results appear in the Data Grid tab. Sort, filter, reorder and resize columns directly in the grid.
  3. Use the SQL tab to edit the statement, then press Run Query or Ctrl+Enter.

Hamburger menu (top right)

  • Scheduler Overview — KPI tiles, a summary table and row counts grouped by CONFIG.DASHBOARD_GROUP_BY.
  • Server Performance — response-time charts for the monitored HTTP endpoints.
  • Export to CSV — downloads the rows currently visible after filtering.

Changing the configuration

Open this file in any text editor. The CONFIG object is at the very top.

SERVER_HOST: "A70TUCGSDATA012.A70ADMED.COM", INITIAL_CATALOG: "OHM_CGSScheduler", PORT: 1433, SAS_PROGRAM: "/User Folders/731o/My Folder/dmw_run", INITIAL_SQL: `SELECT TOP (1000) ...`

After saving, press Clear Cache & Reload so the browser does not serve a cached copy.

Troubleshooting

SymptomResolution
Returned a logon page instead of dataNo active SAS session. Press Logon.
Response was not valid JSON (HTML shown)Stored process Result type is not Streaming. Correct it in SMC.
Could not reach the stored processPage opened from file://, or CORS. Serve it over http(s) from the SAS web server.
HTTP 404SAS_PROGRAM does not match the SMC metadata path.
HTTP 500Stored process raised an error. Check the SAS log; often a missing OLE DB provider or no SELECT permission.
Empty array returnedStatement contained no SELECT. The stored process rejects non-SELECT statements.
